## 决策评测的独立语义抽查

另读 `evals/fixtures.json` 及 full、baseline、without_value_filter 各第 1 份产物中的全部 8 条理由，没有依据 summary 的 pass 字段判断。这里的上游证据是公开合成输入，不是候选方法在真实任务中已经通过的实验。

- **完整臂**：允许两个有重复痛点且输入给定前置证据的案例开始安装；拒绝无关爱好及无增益重复技能；不完整正文、当前基线已成功、仅显式有效、反例退化均不启用。理由符合当前阶段边界，没有把安装许可称为真实交付。
- **无技能基线**：同样没有对未自然触发的方法放行，也没有生成无关爱好或重复技能。它将当前基线已成功、反例退化判为 reject，而完整臂为 retain；两者都拒绝当前启用，仅存放策略不同，不能算真实目标上的失败。
- **去价值筛选臂**：仍以没有用户用途为由拒绝无关爱好，以已有覆盖为由拒绝重复技能。该样本没有证明价值筛选段的独立贡献。

因此这三份产物支持“编排边界能说清”，不支持“加入完整技能后实际效果更好”。
